## 2. 已经定下来的方向，不再重问

产品是 Electron 桌面应用，一期只支持 Mac。三个入口只有任务指挥台、Bots、成长。其他终端以后再做，不恢复 Web 主客户端或手机响应式，也不坚持已经被取代的 SwiftUI 主界面要求。

Bot 长期存在，专属逻辑 Sandbox 不随任务结束销毁；Codex/Cursor/Claude Code CLI 都在 Sandbox 内执行；支持持续交互、本地及远程节点。Orchestrator 本身也是 Bot，可动态创建、委派、验证和重规划任务图。

配套 Resource Server 管基础环境、模板、版本和下载。它不是用户私有知识库、登录凭据仓库或第二个任务调度中心。V1仍是一份本地权威Core，常驻云端Goal调度是未来独立模式。

知识、Skill、规约和经验分开管理，私有资产默认本地；Sandbox按授权装载固定版本。硬权限不靠Prompt实现，Skill安装不能自动获得权限。

用户选择账号与计费来源；Bot默认连接可由用户显式覆盖。ConnectionResolver确定性检查兼容性、数据策略、授权与实际生效凭据；默认不订阅转API、不绕过网关、不借用其他账号。原生登录保留在获准的官方Runtime环境，API秘密由CredentialBroker或受控网关处理。所有厂商认证/分发许可必须核实，尤其Claude订阅产品集成限制，不能把技术可运行当作已获许可。
